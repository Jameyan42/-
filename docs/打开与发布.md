# 打开与更新轻报

## 当前在线入口

https://jameyan42.github.io/-/

当前站点已使用 GitHub Pages 的分支发布模式：Settings → Pages → Source 为 Deploy from a branch，Branch 为 gh-pages，目录为 / (root)。正常更新不需要重复修改该设置。若出现旧页面，可在 Chrome 用 Ctrl + Shift + R（Mac：Command + Shift + R）刷新。不要清理站点数据，以免删除演示记录；可先在“数据管理”导出备份。

## 云端开发与发布

在项目根目录运行：

```sh
npm ci
npm test
QINGBAO_BROWSER_PATH=/usr/bin/chromium npm run test:e2e
npm run export:demo
```

浏览器路径仅适用于当前云机器；其他环境先运行 `npx playwright install chromium`，再使用 `npm run test:e2e`。

将源代码提交、推送至 main 后，执行：

```sh
python3 scripts/publish_pages.py --publish
```

脚本把网页、OCR 引擎/语言数据及虚构样票发布到已有 gh-pages 分支并保留其历史，不移动当前检出、不强制推送、不修改 GitHub 设置。若发布分支出现预期之外的文件，脚本会停止供人工检查。使用现有 GitHub Git 身份认证，不在脚本中写入凭据。main 上的 Validate Qingbao 工作流只验证源码和保存构建产物，不再尝试替用户开启 Pages；实际站点由 gh-pages 更新触发。

推送成功后等待 GitHub Pages 部署完成，并检查实际网站已显示最新功能。环境快照发布与 GitHub 网站发布是两件事。

## 无需安装的本地演示

打开仓库 deliverables/qingbao-demo.zip，点击 Download raw file 下载并解压，在 Chrome 打开 qingbao-demo.html。该 HTML 包含基础界面样式和脚本；OCR 另需配套资源及 HTTP/HTTPS，请使用在线版或开发服务。受企业策略管理的浏览器可能限制本地 HTML，可以使用在线入口。

## 本地开发

需要 Node.js 20.19+ 或 22.12+。在含 package.json 的项目目录执行：

```sh
npm ci
npm run dev
```

按本机终端显示的地址打开网页。云端 localhost 并不是用户电脑的 localhost。

## 数据边界

报销、费用申请、规则、预算和日志仅存在各自浏览器，没有后端或多设备同步；更新网页不会主动重置数据。付款是模拟登记；图片可在浏览器 OCR 处理，保存时仅记录字段、文件名和人工核对来源，不保留原图或原文，台账不验真。请使用虚构资料。单文件换路径后可能被浏览器视为不同存储空间，迁移前先导出备份。

旧版 JSON 备份不含 requests 字段时，恢复报销后保留浏览器已有费用申请；新备份包含该字段，覆盖前会提示申请数量。关联数据须通过校验，避免悬空或超额核销。

## v0.8 新模块入口

打开在线版后，右上角“体验角色”选择“管理员”，侧栏进入“组织架构”或“审批流程”。组织可在部门树/汇报树间切换；审批页可以选择报销或费用申请，试算、存草稿并填写原因发布。右上角“模拟身份”选择具体人员；只有当前节点的指定人员可审批新单据。演示指南已加入组织审批与事前申请路线。

完整备份新增 configuration 字段，包含组织与已发布流程；各单据携带审批快照。旧备份缺少该字段时保留当前配置。旧单据仍使用原固定流程。更新网站无需清除本地数据。

## v0.10 图形组织与财务分工

管理员 → 组织架构，可切换汇报图/部门图、点节点在侧栏维护、快捷添加、缩放和折叠。已有组织没有 CFO 示例时点击“添加 CFO 示例组织”，仅追加示例，不重置已有数据。

管理员 → 审批流程 → 载入财务分工模板 → 填写原因并发布；随后叶禾提交 200 元，沈岚（主管）→ 周宁（财务）→ 高璇（总账）→ 杜川（付款工作台）。总账需要科目和核算归属。旧单据仍走原流程；更新网站无需清理站点数据。

## v0.11 我的已处理

选择实际处理过单据的人员，进入审批中心 → 我已处理。支持类型、结果、关键词及处理时间排序，每页20条，导出当前筛选的所有匹配记录。升级前缺少人员标识的旧日志不自动归属，因此初次打开可能为空；升级后审批、退回和付款开始记录。处理时摘要与单据当前状态分开显示。

## v0.12 查找组织节点

组织架构顶部输入姓名、岗位、部门或角色，必要时限定人员/部门。点结果会展开上级路径、定位节点并打开侧栏；点部门会进入部门树。可点击路径祖先或“定位选中节点”，清除搜索不会删除节点或修改组织。未保存侧栏字段可在切页/身份时选择继续编辑。


## v0.13：按日期回看已处理记录

审批中心 → 我已处理，支持起止日期（可只填一端）与今天、近7天、本月、上月、不限日期快捷选择。处理时间按当前浏览器本地时区划分日期，包含起止两天；近7天含今天，本月至今天。概览与页签保持本人全部处理次数，日期提示及页脚显示当前匹配次数，二者不混用。

日期与类型、结果、关键词共同筛选；改变日期回到第一页。CSV导出全部匹配页，并追加本地处理日期、筛选起止日期和时区，保留原始ISO处理时间。起止倒置时显示错误、禁用导出并标记结果未计算。清除筛选、切换身份/页面/待办页签或刷新会清空日期，不写入业务数据。

演示：赵航实际通过一笔报销 → 我已处理 → 今天，看到本人操作 → 改为上月观察空结果 → 填反起止日期观察错误 → 清除筛选恢复。没有真实历史日期时不要编造上月业务记录。生产权限、服务端统一业务时区、报销发生日期筛选和跨用户统计尚未实现。
