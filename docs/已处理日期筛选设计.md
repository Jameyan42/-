# 已处理记录日期筛选设计

## v0.13：按日期回看已处理记录

审批中心 → 我已处理，支持起止日期（可只填一端）与今天、近7天、本月、上月、不限日期快捷选择。处理时间按当前浏览器本地时区划分日期，包含起止两天；近7天含今天，本月至今天。概览与页签保持本人全部处理次数，日期提示及页脚显示当前匹配次数，二者不混用。

日期与类型、结果、关键词共同筛选；改变日期回到第一页。CSV导出全部匹配页，并追加本地处理日期、筛选起止日期和时区，保留原始ISO处理时间。起止倒置时显示错误、禁用导出并标记结果未计算。清除筛选、切换身份/页面/待办页签或刷新会清空日期，不写入业务数据。

演示：赵航实际通过一笔报销 → 我已处理 → 今天，看到本人操作 → 改为上月观察空结果 → 填反起止日期观察错误 → 清除筛选恢复。没有真实历史日期时不要编造上月业务记录。生产权限、服务端统一业务时区、报销发生日期筛选和跨用户统计尚未实现。

## 取舍与验证

筛选依据是每一次操作的处理时间，不是报销发生日期或单据最后更新时间。同一单据在不同日期处理可以落入不同范围，原操作摘要不改写。操作时间保留ISO瞬时时间；用本地年月日比较避免夏令时23/25小时日的毫秒误差。日期输入先验证真实日历日期，不能将错误值静默转为其他日期。

日期是临时视图状态，默认不限，升级不迁移/清理已有记录。浏览器时区不同可能使同一瞬间落在不同日期，页面与CSV明确时区，不能当作服务端统一财务日口径。当前无自定义时区选择、服务器审计、多人汇总或定时报表。

复盘：增加筛选后必须同时处理概览、空态、错误态、分页和导出，否则会产生表格与导出数量不一致的问题。用上海午夜和纽约夏令时边界验证日期语义，用25条记录验证跨页全量导出，而不以控件可点代替规则验收。没有真实用户测试，不宣称查找耗时下降。
