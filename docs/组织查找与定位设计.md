# v0.12 组织画布查找与定位

## 问题与交互

图形组织扩大后，管理员需要在宽画布中找到员工、岗位或部门。增加姓名、岗位、部门和角色关键词搜索，支持人员与部门/仅人员/仅部门范围。忽略首尾空格和英文字母大小写，名称精确匹配优先，其次名称前缀，再按名称稳定排序。停用人员仍可找到，明确标注“已停用”，避免将停用误解为删除。

搜索只展示结果，不修改人员、部门或审批配置。结果全部在可滚动列表中，显示匹配数量和无结果提示，不把画布中无关节点过滤删除。点选人员保持当前图模式；点选部门自动切到部门树，避免在人员汇报图中定位不存在的部门节点。

## 展开、聚焦和路径

点击结果时根据完整组织数据寻找根到目标的路径，只展开路径上的祖先节点，保留其他分支和目标本身的折叠状态。缩放至少恢复到65%，将目标卡片中心移动到画布可视范围，打开资料侧栏，并以键盘焦点标识节点。所有变化仅是视图状态，不写业务配置。

新增“汇报路径 / 归属路径”导航，可点击任意祖先重新定位；“定位选中节点”可在手动平移后回到当前选择。清除搜索只重置关键词和范围，保留当前节点与视图展开状态。刷新页面重置搜索，不持久化搜索词。

## 未保存保护

资料侧栏已有未保存修改时，搜索、搜索范围、清除、定位或切换视图等重新渲染操作提示是否放弃。取消时保留编辑字段和原搜索值。补充切换页面、角色、具体人员的同类保护，取消时恢复原选择值。现有缩放/折叠保护保持生效。只读角色也可查找定位，但不显示维护表单或新增入口。

## 验证与兼容

人员和部门键按第一个冒号分隔，保留标识中的其他冒号；恢复的合法自定义标识不会被截断。名称、岗位和路径等文本均转义显示。节点不存在时停止定位并提示，不修改原折叠集合或配置。

原有CFO组织图、财务分工、待办、已处理记录、备份和审批路径保持不变。不增加数据格式字段，不重置既有记录。搜索词和匹配结果不发送给外部服务。

## 范围

当前为关键词包含匹配，不支持拼音、模糊纠错、组合布尔条件或独立通讯录。仍无拖拽修改上下级和生产账号权限。交互来自项目流程分析和走查，尚未取得真实企业管理人员的可用性数据。
