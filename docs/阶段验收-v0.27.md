# v0.27 阶段验收：PDF 发票识别

日期：2026-10-24（Asia/Shanghai）。

## 交付

报销快速OCR、报销/对公结构化采集及已存发票原件识别均支持PDF。PDF电子版和扫描版在本浏览器选页、预览、转图，再真实运行既有Tesseract.js；每次只识别所选一页，人工核对后应用或加入票面清单。来源保留页码、原件引用不改，备份保留原文件字节。

同源PDF.js模块、Worker、字体/CMap/解码资源及许可证随现有站点部署，205项OCR资源约21.1 MB（按需加载，非一次全部下载）。新增公开两页虚构样票，第2页为265元发票；新增电子文字、加密及21页测试夹具。详见[设计与产品取舍](PDF发票识别设计.md)。

## 交付材料与边界

需求、演示、OCR设计复盘、项目待办、Excel迭代表同步维护；演示ZIP现9项，新增虚构PDF及说明，逐字节核对源文件。既有4页项目案例和7页面试PDF继续提供，本阶段未改变面试主路线。

PDF识别最多6 MB、20页；单次仅一页，不批量合并多票金额。加密需用户自行解密；损坏/资源失败可手工回退。原件留存仍限1 MB/份、1.5 MB/单，每个原件只关联一张票面，多票文件先拆分。电子PDF目前也转图OCR，未做文本层优先抽取；不保证任意版式准确率，不支持红票/外币/官方验真。合同PDF正文提取与本次发票识别不同，仍未提供。

没有外部OCR API、模型费用、真实财务资料、账号权限或公开范围变化；身份和付款仍为演示机制。
