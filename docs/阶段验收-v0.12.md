# v0.12 组织画布查找与定位验收

## 交付

姓名/岗位/部门/角色关键词搜索，人员/部门范围，停用标记和匹配数量；定位时展开祖先、保留其他折叠、居中和至少65%可读缩放；部门结果自动切归属图；路径导航与回到选中节点；清除不改变组织；搜索/切页/切身份的未保存侧栏保护；自定义冒号标识兼容。演示指南、需求、面试案例及PDF同步更新。

## 测试证据

- 53项业务测试全部通过，新增5项覆盖多字段匹配、空白/大小写、不修改数据、祖先展开/保留折叠、视图和路径、停用及未知节点、冒号标识。
- 49项Chromium场景整套通过，新增5项覆盖折叠下级查找定位、部门/岗位筛选及路径导航、只读与停用/文本转义、未保存取消保护、手机重新定位与缩放。
- 图形编辑、财务总账付款、审批与个人已处理记录、OCR、预算、备份等原场景保持通过。
- 构建和单文件导出成功；生产同构 `/-/` 页面验证折叠CFO后定位叶禾、汇报路径/资料侧栏、部门切换、配置未被改写、手机整页无溢出，无JS错误；检查桌面截图，更新作品PDF。

## 取舍与边界

搜索结果定位而不删减完整画布，避免丢失关系语境；只展开目标祖先，不展开整个组织；清除保留当前选择和展开状态。搜索词不持久化，不写业务配置或发送外部请求。无拼音、模糊纠错、复杂条件或拖拽改上级。未获得真实管理人员的可用性数据，不以测试通过宣称效率收益。

发布验收待部署核对后补记；浏览器交互证据来自本地同构生产产物，线上使用HTTPS内容散列核对，不绕过云端浏览器证书验证。
