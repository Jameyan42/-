## 完成内容与边界

| 内容 | 实现 |
|---|---|
| 法人/金额审批政策 | 独立配置，整数分边界，日期/职级/费用类型；专属优先、集团回退、缺失或冲突不默认通过 |
| 具名审批 | 根据原组织解析主管/部门负责人，复用原具名校验；记录人员/节点/意见/时间/报销版本/政策版本 |
| 正常等待及异常 | 待节点REVIEW，越权/顺序错误/职责冲突/有效驳回拦截；退回或驳回不能原版本覆盖 |
| 附件 | 真字节、业务分类、逐票关联、多票PDF人工关联、上传人员时间、保存与核实分离、查看/下载/删除/替换 |
| 出差申请例外 | 原系统批准申请＋完整具名同流程操作＋人员部门目的地日期匹配；不能只改状态文字 |
| 统一审核与财务 | 一次六规则，A/B独立证据；R006需两个子项PASS才允许独立财务批准，无财务前置循环 |
| 修改及历史 | 原批次、原审批不改，资料/文件变化新版本重提；政策更新新提交采用新版本，旧上下文固定 |
| 操作日志 | 创建、变更、提交、批准/驳回/退回、自动审核、财务最终复核及配置变更；前后值/原因/身份/时间 |
| 界面 | 原四导航内扩展，不新增独立R006工具；业务审批进度与规则/节点状态明确区分 |

真实账号、签名、组织撤权跨设备联动、BPM、税务验真、银行支付、自动凭证不在本次范围。当前全输入变化均保守触发重新审批，不声称已实现精细字段差异策略。
