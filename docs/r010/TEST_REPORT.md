## 发现的问题与处理

1. PaddleOCR3.x已安装，但官方模型源403：尝试官方多个源后切换包内含预训练Paddle模型的RapidOCR。原生3.x仅提供可选适配，不声称已推理验证。Windows依赖路径说明已给，但未在Windows实机执行。
2. 同一行净额/税额可能混为同一个金额候选：共享提取器按显式字段标签分段，新增金额分/0税额/负数/冲突及分栏单测；不倒推未知金额。
3. 重识别缺失字段可能沿用旧票数据：成功识别时缺失/冲突/无效字段清空，不伪装成新票提取；识别过程用户修改过的字段保留；失败时保留原表单。
4. 人工确认后继续改金额可能继续显示“已核对”：原始确认快照保留，当前状态重新待核对，实际页面测试通过。
5. 初次完整浏览器运行有6项旧流程失败；修改前HEAD acb445a对照6项全部通过。运行时热更新和共享测试服务退出干扰了两轮检查，第二轮出现连接拒绝，不能把这两轮称为全量通过。改为稳定代码、独立服务所有权及独立本机测试配置后重新执行最终回归，最终数量见上文。
6. 原S001原件容量和本地存储、全局备份边界不改变。每票3次识别上限明确报错、不删旧结果。详见使用限制。
